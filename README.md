# 📖 বাংলা মাধ্যমে হিন্দি বর্ণমালা শিক্ষা (Hindi Alphabet for Bangla Speakers)

> **"আপনি যদি বাংলা পড়তে পারেন, তবে হিন্দির অর্ধেক বর্ণমালা আপনার ইতোমধ্যে জানাই আছে!"**

একটি আধুনিক, দ্রুতগতির এবং মোবাইল-বান্ধব স্ট্যাটিক ওয়েব অ্যাপ্লিকেশন যা বাংলাভাষীদের দেবনাগরী (হিন্দি) বর্ণমালা সহজে ও দ্রুত শিখতে সাহায্য করে। জনপ্রিয় জাপানি বর্ণমালা শেখার সাইট [Tofugu's Kana Quiz](https://kana-quiz.tofugu.com/) এর দ্রুত ফিডব্যাক ও মিনিমালিস্ট শিক্ষার দর্শন দ্বারা অনুপ্রাণিত।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **বাংলা-হিন্দি সেতুবন্ধন (The Bangla Bridge)**:
   - দেবনাগরী ও বাংলা লিপির জন্ম একই প্রাচীন ব্রাহ্মী লিপি থেকে।
   - বর্ণমালার বর্গের সাদৃশ্য (ক-বর্গ, চ-বর্গ, ট-বর্গ, ত-বর্গ, প-বর্গ)।
   - বাংলা **কারচিহ্ন** ও হিন্দি **মাত্রাসমূহ** (Matras)-এর হুবহু মেলবন্ধন।
   - বাংলা **যুক্তাক্ষর** ও হিন্দি **সংযুক্তাক্ষর** (Conjuncts)-এর তুলনা।
   - উচ্চারণের সুনির্দিষ্ট পার্থক্য (যেমন: দন্ত্য 'ত' বনাম মূর্ধন্য 'ট', 'व' বনাম 'ब', 'শ'/'ষ'/'স'-এর উচ্চারণ)।

2. **অ্যাভ্রো (Avro) ও বাংলা উভয় মাধ্যমে অনুশীলন**:
   - **MCQ কুইজ**: কীবোর্ডের `1`, `2`, `3`, `4` চাপলেই চোখের পলকে উত্তর বাছাই।
   - **সরাসরি অ্যাভ্রো টাইপিং টেস্ট (Tofugu Style)**: হিন্দি বর্ণ দেখে সরাসরি ইংরেজি কিবোর্ডে `ka`, `kha`, `ga` টাইপ করে এন্টার চাপুন।
   - **বিভ্রান্তিকর বর্ণ ড্রিল (Confusing Pairs)**: যে বর্ণগুলো সবচেয়ে বেশি প্যাঁচ লাগায় (যেমন: ब/व, ঘ/ध, त/थ, ट/ठ/ড/ঢ, प/ফ/फ़)।
   - **উচ্চারণ শুনে উত্তর নির্বাচন (Sound Quiz)**: ব্রাউজারের নেটিভ স্পিচ সিন্থেসিসের মাধ্যমে উচ্চারণ শুনে সঠিক বর্ণ নির্ণয়।

3. **দুর্বল বর্ণ ট্র্যাকিং (Weak Characters Drill)**:
   - কোনো প্রশ্ন ভুল হলে ব্রাউজার স্বয়ংক্রিয়ভাবে `localStorage`-এ তা চিহ্নিত করে।
   - "🎯 দুর্বল বর্ণ অনুশীলন" বোতামে চাপ দিলে কেবলমাত্র ভুল হওয়া বর্ণগুলোর ওপর বারবার কুইজ নেওয়া হয়।
   - ৫ বার নির্ভুল উত্তর দিলে বর্ণটি "আয়ত্তে এসেছে" (Mastered) হিসেবে গণ্য হয়।

4. **১০০% প্রাইভেট ও অফলাইন ফ্রেন্ডলি**:
   - কোনো অ্যাকাউন্ট বা লগইন তৈরির ঝামেলা নেই।
   - আপনার সমস্ত অগ্রগতি সম্পূর্ণ আপনার নিজের ব্রাউজারে সংরক্ষিত থাকে।

5. **লাইভ ভিজিটর কাউন্টার (Visitor Counter)**:
   - GitHub Pages-এর জন্য বিশেষভাবে তৈরি রিল্যায়বল ভিজিটর কাউন্টার।
   - অফলাইন ক্যাশিং ও রিলোড স্প্যামিং প্রটেকশন সহ সরাসরি পরিদর্শক সংখ্যা প্রদর্শন করে।

## 🚀 GitHub Pages-এ সম্পূর্ণ বিনামূল্যে হোস্ট করার নির্দেশিকা

এই প্রজেক্টটি কোনো ব্যাকএন্ড বা ডেটাবেজ ছাড়া সম্পূর্ণ ভ্যানিলা এইচটিএমএল, সিএসএস ও জাভাস্ক্রিপ্ট দিয়ে তৈরি। তাই এটি GitHub Pages-এ তাৎক্ষণিকভাবে চালানো যায়:

1. **গিটহাবে একটি নতুন পাবলিক রিপোজিটরি তৈরি করুন**:
   - উদাহরণ: `hindi-learning`
2. **কোডগুলো রিপোজিটরিতে পুশ করুন**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Hindi Learning Platform"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/hindi-learning.git
   git push -u origin main
   ```
3. **GitHub Pages চালু করুন**:
   - রিপোজিটরির **Settings** ট্যাবে যান।
   - বামপাশের মেনু থেকে **Pages**-এ ক্লিক করুন।
   - **Source** হিসেবে `Deploy from a branch` সিলেক্ট করুন।
   - **Branch** মেনু থেকে `main` এবং ফোল্ডার `/ (root)` সিলেক্ট করে **Save** দিন।
4. **সম্পন্ন!**:
   - ২ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে:
     `https://YOUR_USERNAME.github.io/hindi-learning/`

## ⌨️ কীবোর্ড শর্টকাট (Desktop Fast Practice)

- `1`, `2`, `3`, `4`: প্রথম, দ্বিতীয়, তৃতীয় ও চতুর্থ উত্তর নির্বাচন
- `Space` অথবা `Enter`: পরবর্তী প্রশ্নে যাওয়া
- `Enter` (টাইপিং মোডে): অ্যাভ্রো টাইপ যাচাই করা
